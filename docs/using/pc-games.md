# PC games

Epic Games, GOG and Amazon Games go through Heroic Games Launcher, and the games
play from Steam with Proton. Heroic publishes only x86 Linux builds, so Zaviya
Loadout installs an
[ARM64 build](https://github.com/hashtagbasit/arm64-linux-apps) made from
Heroic's source.

## Steps

1. In Zaviya Loadout, open **PC Games** and install **Heroic Games Launcher**.
2. Open Heroic from the Steam library and sign in to the stores.
3. Install games in Heroic.
4. In Zaviya Loadout's **PC Games** tab, select **Add to Steam** next to each game,
   or **Add all to Steam**.

The games appear in the Steam library with their artwork, set up to run with
Proton.

!!! note

    Launch these games from Steam, not from Heroic. Games whose anti-cheat
    does not support Linux will not run, as on a Steam Deck.
