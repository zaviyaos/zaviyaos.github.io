# Community and support

Zaviya is free and developed in the open. Questions, bug reports, test results
and donations all go to the channels below.

## Get help

| Need | Where |
|---|---|
| Install help and general questions | [Discord](https://discord.gg/EP53nZYvg) |
| Bug reports and device requests | [GitHub issues](https://github.com/hashtagbasit/SteamOS-ARM-Port/issues) |
| Self-service answers | [Troubleshooting](../help/troubleshooting.md), [Known issues](../help/known-issues.md) and the [FAQ](../help/faq.md) |

Include the device model and the [debug logs](../help/troubleshooting.md#debug-logs)
in a bug report.

## Test and report

Community testing decides which devices are marked as tested. A report is useful
even when everything works. Running Zaviya on a device and reporting the result
helps other owners, and a star on the
[GitHub repository](https://github.com/hashtagbasit/SteamOS-ARM-Port) helps the
project reach them.

## Send a device

A new handheld is added only when someone can test it. A spare device,
supported or not, is the fastest way to get it supported. Contact the project on
[Discord](https://discord.gg/EP53nZYvg) or
[GitHub](https://github.com/hashtagbasit/SteamOS-ARM-Port/issues).

## Contribute

Issues and pull requests are welcome on
[GitHub](https://github.com/hashtagbasit/SteamOS-ARM-Port). Images are built from
the repository on an ARM64 Linux machine, and the build steps are in
[building.md](https://github.com/hashtagbasit/SteamOS-ARM-Port/blob/main/docs/building.md).
