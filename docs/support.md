# Support

Zaviya is free and I build it in my spare time.

## Support development

Donations buy test hardware.

[:simple-kofi: Ko-fi](https://ko-fi.com/aimalb){ .md-button .md-button--primary }
[:fontawesome-brands-paypal: PayPal](https://paypal.me/Basit2000){ .md-button }

## Send a device

The community tests most of the handhelds here, and a new one only gets added
when someone can try it. A spare handheld, supported or not, helps the most.
Message me on [Discord](https://discord.gg/EP53nZYvg) or
[GitHub](https://github.com/hashtagbasit/SteamOS-ARM-Port/issues).

## Test and report

Run it and tell us how it went, even if everything works. A star on the
[GitHub repo](https://github.com/hashtagbasit/SteamOS-ARM-Port) helps too.
